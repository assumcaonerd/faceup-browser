# Política de segurança

Não publique vulnerabilidades, credenciais ou imagens privadas em issues públicas. Relate o problema diretamente ao mantenedor pelo recurso privado de aviso de segurança do GitHub, quando disponível.

Inclua versão afetada, impacto, passos mínimos para reprodução e uma sugestão de correção. Nunca envie fotografias reais de terceiros como prova; use arquivos sintéticos.
