# Como contribuir

Obrigado por ajudar o FaceUp Browser. Abra uma issue antes de mudanças grandes e envie cada contribuição em um pull request pequeno e bem explicado.

## Antes de enviar

```bash
npm ci
npm run lint
npm test
npm run build
```

- Não inclua chaves, tokens, fotografias pessoais ou resultados contendo pessoas identificáveis.
- Preserve o modo local e informe claramente qualquer fluxo que envie imagens para terceiros.
- Inclua testes para correções e funcionalidades novas.
- Mudanças de segurança, privacidade, dependências ou processamento de imagens exigem justificativa técnica.

Ao contribuir, você concorda que seu código será distribuído sob a licença MIT do projeto.
